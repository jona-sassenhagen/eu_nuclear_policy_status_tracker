A dashboard for tracking where EU states stand on nuclear power.

Tracking status as:
- phase-out decided
- phase-out completed
- phase-out reverted
- building new reactors

Layout
- in the middle, a map of the EU
- each country colored by main status
- surrounded by flags which give detailed status, including:
	- how many reactors are operating
	- how many reactors being built
	- link to the most recent news

Also a second site one can click through where sources are given for each country's status
